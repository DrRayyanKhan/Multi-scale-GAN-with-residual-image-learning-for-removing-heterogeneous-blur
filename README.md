# Multi-Scale GAN with Residual Image Learning for Removing Heterogeneous Blur

This repository contains the source code and supporting scripts associated with the following publication:

**Khan RA, Luo Y, Wu FX. Multi-scale GAN with residual image learning for removing heterogeneous blur. _IET Image Processing_. 2022;16(9):2412–2431.**  
https://doi.org/10.1049/ipr2.12497

## Overview

The code provided in this repository was developed as part of the research presented in the publication above.

The study proposes a **multi-scale generative adversarial network (GAN) with residual image learning for the removal of heterogeneous blur from images**.

This repository is made available to support:

- research reproducibility;
- academic and educational use;
- comparison with related image-restoration methods;
- further methodological development; and
- extension of the proposed approach.

Users should refer to the original publication for complete details regarding the model architecture, methodology, datasets, training procedure, experimental design, and evaluation.
